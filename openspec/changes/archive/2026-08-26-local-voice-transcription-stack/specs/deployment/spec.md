# Delta spec: deployment

## Purpose

Определяет требования к установке и эксплуатации стека: подготовка окружения DGX Spark (ARM64 + Blackwell), постоянная работа сервиса, сетевой доступ с клиента и проверка работоспособности.

## ADDED Requirements

### Requirement: Проверка пути инференса на GB10 до основных работ

Целевой путь инференса на DGX Spark — Docker-окружение из рецепта `paruparu/faster-whisper-dgx-spark` (наш сервис запускается внутри его контейнера); собственное venv-окружение является альтернативой. Процедура развёртывания ДОЛЖНА начинаться со спайка: подтверждение, что рантайм рецепта реально использует GPU (sm_121) на DGX Spark и выдаёт корректную расшифровку тестовой фразы. Результат спайка ДОЛЖЕН (MUST) быть зафиксирован в docs; при неудаче применяется фолбэк-лестница из design.md.

#### Scenario: Спайк подтверждает GPU-инференс

- **WHEN** на чистой машине выполнены шаги спайка и запущена транскрибация тестового WAV
- **THEN** логи/мониторинг показывают использование CUDA (не CPU), расшифровка корректна, результат зафиксирован в docs

### Requirement: Постоянная работа сервиса

Сервис ДОЛЖЕН (MUST) запускаться как постоянный процесс: автостарт при загрузке машины, автоматический перезапуск после падения, управляемые логи. Модель загружается один раз при старте процесса.

#### Scenario: Перезапуск после падения

- **WHEN** процесс сервиса аварийно завершается
- **THEN** он автоматически перезапускается, модель загружается заново, последующие запросы обрабатываются без ручного вмешательства

#### Scenario: Переживает ребут машины

- **WHEN** DGX Spark перезагружается
- **THEN** сервис стартует автоматически и `/health` отвечает готовностью без ручных действий

### Requirement: Сетевой доступ в пределах локальной сети

Сервис ДОЛЖЕН (MUST) быть доступен с MacBook по локальной сети (LAN). Слушающий порт конфигурируем; сервис ДОЛЖЕН (MUST) быть привязан к интерфейсу локальной сети и НЕ ДОЛЖЕН (MUST) (MUST NOT) быть доступен из внешних сетей (без проброса портов на роутере). Удалённый доступ вне домашней сети не предусматривается.

#### Scenario: Диктовка из домашней сети

- **WHEN** MacBook подключён к той же LAN, что и Spark
- **THEN** клиент достигает сервиса по адресу `http://<spark-ip>:<port>` без дополнительной сетевой инфраструктуры

#### Scenario: Нет доступа извне локальной сети

- **WHEN** запрос к сервису приходит из сети, не являющейся доверенной локальной (например, через внешний адрес роутера)
- **THEN** соединение отклоняется (порт недоступен), проброс портов не настроен

### Requirement: Управление секретами

Токен доступа ЗАДАЁТСЯ (MUST) через переменные окружения или локальный файл конфигурации вне git (.env в .gitignore). Инструкция развёртывания ОБЯЗАНА (MUST) описывать генерацию токена.

#### Scenario: Генерация токена при установке

- **WHEN** оператор следует инструкции установки
- **THEN** генерируется случайный токен, он попадает в конфиг сервера и в настройку клиента, и его нет ни в одном файле под контролем версий

### Requirement: Процедура проверки работоспособности

Инструкция ДОЛЖНА (MUST) включать smoke-check: health-check запрос и контрольную транскрибацию короткого WAV с ожидаемым результатом, выполняемые одной-двумя командами после установки.

#### Scenario: Smoke-check после установки

- **WHEN** оператор выполняет команды smoke-check из инструкции
- **THEN** health возвращает готовность, контрольная фраза распознана верно, установка считается завершённой
