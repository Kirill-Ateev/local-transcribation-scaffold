# Клиент: OpenWhispr на MacBook

Готовое приложение без форка. Схема: глобальный хоткей → запись → сервис на
DGX Spark → вставка текста в позицию курсора.

## 1. Установка и разрешения macOS

1. Установите OpenWhispr (github.com/OpenWhispr/openwhispr, релизы под macOS).
2. При первом запуске выдайте разрешения:
   - **Микрофон** — Системные настройки → Конфиденциальность → Микрофон;
   - **Accessibility** — Системные настройки → Конфиденциальность → Универсальный
     доступ (нужно для вставки текста в позицию курсора).
3. Перезайдите в систему после выдачи разрешений и убедитесь, что диктовка
   работает (сценарий «чистой установки»).

## 2. Подключение к сервису на Spark (custom provider)

В настройках провайдера добавьте OpenAI-совместимый endpoint:

| Поле | Значение |
|---|---|
| Base URL | `http://<spark-ip>:8337` — OpenWhispr сам добавляет `/audio/transcriptions`; вариант с `/v1` тоже работает (сервер принимает оба пути) |
| API key | токен из `server/.env` на Spark (`TRANSCRIBE_TOKEN`); если на сервере `AUTH_REQUIRED=0` — можно оставить пустым |
| Model | любое значение, например `breeze-asr-25` — сервис игнорирует селектор |
| Language | пусто — сервер сам определяет язык (DEFAULT_LANGUAGE=auto); можно зафиксировать `zh`/`en`/`ru` |

Если OpenWhispr не позволяет передать Bearer-токен (режим Self-Hosted для
локальной сети) — включите на сервере `AUTH_REQUIRED=0` в `server/.env` и
перезапустите контейнер; это безопасно, пока сервис доступен только из LAN.

Про язык: резидентная модель — Breeze-ASR-25 (fine-tune Whisper large-v2 от
MediaTek), сильнее всего в традиционном китайском и английском, включая их
смешение в одной фразе. Если авто-детект на коротких диктовках ошибается —
зафиксируйте язык в настройке Language или в поле `language` запроса.

Промпт и post-обработка — на сервере: promptv3 (сохранение латиницы
терминов) и capglue (починка склеек предложений) применяются ко всем
запросам автоматически; в OpenWhispr ничего настраивать не нужно.

Известные особенности Breeze-ASR-25 (из бенчмарка, не чинятся регексом):

- **Вопросительные знаки** ставит неохотно («лучше промолчать») — смысловые
  вопросы иногда придётся править руками;
- **Заимствования тянет в латиницу**: «текст» → `text`, «спикер» → `Speaker`
  (плата за высокий EPI — сохранение английских терминов);
- **Склонения через апостроф**: `fine-tune'ы`, `prompt'у` — обычно удобно,
  в официальных документах править руками;
- **Склейки предложений** — уже чинит capglue на сервере.

Спайк-чеклист первого подключения (зафиксируйте результаты здесь):

- [ ] Provider сохраняет base URL с нестандартным портом
- [ ] Авторизация проходит: либо Bearer-токен уходит заголовком (AUTH_REQUIRED=1),
      либо на сервере задан AUTH_REQUIRED=0 (в логах 200, а не 401)
- [ ] Запись отправляется как multipart с полем `file`
- [ ] Таймаут клиента достаточен (> 5 c) для короткой диктовки
- [ ] Текст вставляется в позицию курсора; фокус приложения не теряется
- [ ] При выключенном Spark появляется уведомление об ошибке, текст НЕ вставляется
- [ ] При неверном токене видно сообщение об ошибке авторизации

Если пункт невыполним средствами OpenWhispr — зафиксировать отклонение и
вернуться к решению D4 (Handy / минимальный форк), не молча менять поведение.

## 3. Поведение при диктовке

- Вставка в **терминал**: текст попадает в командную строку, но Enter не
  нажимается автоматически — команда не выполняется сама. Проверить явно.
- Между устройствами: используйте по очереди; второй запрос во время обработки
  первого дождётся своей очереди (FIFO) и вернётся чуть позже.

## 4. Латентность (протокол замера для задачи 5.5)

Цель: медиана ≤ 3 c от отпускания клавиши до появления текста для фраз 5–10 c.

1. Условия: Spark по Ethernet; затем тот же прогон по Wi-Fi.
2. 10 фраз по 5–10 секунд (можно из `eval/phrases.yaml`).
3. Замер: экранная запись 60 fps; кадр отпускания клавиши → кадр появления
   текста; время = кадры / 60. Альтернатива — секундомер по видеозаписи.
4. Результаты таблицей сюда:

| # | Ethernet, c | Wi-Fi, c |
|---|---|---|
| 1 | _заполнить_ | _заполнить_ |
| … | | |
| **медиана** | _заполнить_ | _заполнить_ |

Если медиана по Ethernet > 3 c — вернуться к риску «отказ от turbo» в design.md.
